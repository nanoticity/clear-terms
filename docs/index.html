Clear Terms

A Chrome extension that reads Terms of Service pages and classifies each clause using a machine learning model trained on human-annotated data. Everything runs locally in your browser — nothing is sent to a server.

How It Works

The extension runs a scikit-learn pipeline ported to JavaScript. Here's what happens when you click it.

1

Text Extraction

A content script pulls the visible text from the current page via the DOM. No screenshots, no network requests.

2

Clause Splitting

The text is split on paragraph boundaries. Fragments shorter than 80 characters, section headers, and numbered labels are filtered out with simple regex rules. What remains are the substantive clauses.

3

TF-IDF Vectorization

Each clause is tokenized into unigrams and bigrams, then projected into a 10,000-dimensional TF-IDF space. Term frequencies are weighted by IDF and L2-normalized. This is the same math as scikit-learn's TfidfVectorizer, reimplemented in JS using a sparse representation.

4

LinearSVC Classification

The TF-IDF vector is multiplied against a coefficient matrix (4 classes × 10,000 features) with intercept terms. The highest decision score wins. Confidence comes from a softmax over the raw scores. Class weights are balanced to account for label imbalance in the training data.

5

Grading

Clause predictions are counted across four labels: good, neutral, bad, and blocker. Blockers are weighted 2× in the bad ratio. The ratio maps to a letter grade from A to F.

Model Details

Training Data

The model is trained on the ToS;DR dataset — thousands of ToS clauses classified by volunteers as good, neutral, bad, or blocker. Only approved points with quoted text are used for training.

Vectorizer

TfidfVectorizer(ngram_range=(1,2), max_features=10000). The vocabulary and IDF weights are exported from the trained sklearn pipeline to a JSON file (698 KB) that ships with the extension.

Classifier

LinearSVC(class_weight='balanced', max_iter=5000). Coefficients and intercepts are exported to JSON. Inference is one matrix multiply — fast on any hardware.

Privacy

The model file is bundled with the extension. Text extraction, vectorization, and classification all happen in the browser tab. No data is sent anywhere. No analytics. No telemetry.

Grading Scale

The grade is based on the ratio of bad+blocker clauses to total clauses. Blockers count double.

A
Less than 10% bad, more than 40% good.

The policy is mostly fair. Few or no problematic clauses.

B
Less than 20% bad, more than 25% good.

Generally reasonable, with some clauses worth reading.

C
Less than 35% bad.

Mixed. There are enough problematic clauses to warrant a closer look.

D
Less than 50% bad.

A significant portion of the policy is unfavorable to users.

F
50% or more bad.

The majority of clauses are problematic or outright hostile. Read carefully before agreeing.

Install

Clear Terms isn't on the Chrome Web Store. You install it manually by loading the unpacked extension.

1

Download

Get the extension as a ZIP file.

clear-terms.zip
2

Unzip

Extract the ZIP to a folder somewhere you won't accidentally delete it. You'll point Chrome to this folder.

3

Enable Developer Mode

Open Chrome and go to:

chrome://extensions

Flip the Developer mode toggle in the top-right corner.

4

Load Unpacked

Click Load unpacked in the top-left, select the folder from Step 2. The extension icon appears in your toolbar — done.
